# Contributing

Keep the common pipeline small and add a verified vertical slice before expanding
domain promises. Use original/synthetic or appropriately licensed test assets. Include
the license and provenance of any external fixture. No private project history or local
personal paths may enter examples, logs or documentation.

Run the offline suite, privacy audit and skill check. Run actual Blender integration
tests for runtime changes and the official MCP smoke test for adapter changes. Record
versions and distinguish unit mocks, headless Blender and MCP runtime evidence.
CI configuration is not proof that hosted CI ran. See [testing](docs/testing.md).

Workflow changes must preserve refusal of unapproved transitions, stale artifacts,
unreviewed images and unauthorized target edits. Validators must never repair data.
Tests should verify meaningful state/geometry invariants, not implementation wording.
Describe what changed, why, validation and remaining limitations in review requests.
Contributions use the project's MIT license; do not import incompatible upstream code.
