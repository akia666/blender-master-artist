# New model

Inspect the scene even for a new asset; unrelated objects remain preserved. Establish
asset use, references, coordinate system, scale basis and target budget. Start a workflow
journal, inventory existing names and save an initial checkpoint. Submit research.

After explicit approval, advance and reserve new object names with `register_new`.
Create a checkpoint, request a scoped edit permit, and build the blockout. Use the
relevant domain skill only. Capture four views, inspect proportions, validate source
and evaluated meshes and submit the blockout bundle. Do not approve on the user's behalf.

Repeat the stage contract through major/secondary forms, details, topology, materials
and final validation. Add new details as separate components when appropriate.
Reopening approved primary geometry needs authorization; later-stage permission to add
details is not blanket permission to rescale an approved body. Document remaining issues
and uncertainty before asking for the next concrete review.
